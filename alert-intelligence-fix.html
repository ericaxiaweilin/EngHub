🔧 预警情报模块跳转修复方案

问题描述

当前预警情报页面（/alert-intelligence）被错误地归类到 MES模块 (g-mes) 下，导致点击后会跳转到 MES 相关的子菜单。

实际上，预警情报是跨所有模块的通用功能，应该作为一个独立的全局模块存在。

修改位置

文件：frontend/src/components/Layout.tsx

当前代码（错误）FIX
const ROUTE_MODULE_MAP: [string, string][] = [ ... ['/report-center', 'g-mes'], ['/alert-intelligence', 'g-mes'], ... ]
修复后代码（正确）NEW
// 添加预警情报分组 'g-alert': , const ROUTE_MODULE_MAP: [string, string][] = [ ... ['/report-center', 'g-mes'], ['/alert-intelligence', 'g-alert'], // ← 改为独立模块 ... ]
在 menuIcons 映射中添加 g-alert
const menuIcons: Record = { 'g-dashboard': <DashboardOutlined />, 'g-mes': <AppstoreOutlined />, 'g-qms': <SafetyOutlined />, 'g-wms': <InboxOutlined />, 'g-equipment': <ToolOutlined />, 'g-aps': <FieldTimeOutlined />, 'g-collab': <ThunderboltOutlined />, 'g-hr': <TeamOutlined />, 'g-alert': <AlertOutlined />, // ← 添加这行 ... }
在 i18n 语言文件中添加翻译

文件：frontend/src/i18n/locales/zh-CN.json

{ "menu": { "g-alert": "预警情报", // ← 添加这行 "/alert-intelligence": "预警情报", ... } }
✅ 修复效果
  • 预警情报将作为独立模块出现在侧边栏顶部
  • 不再依赖 MES 模块，可在任何模块中访问
  • 点击后直接进入 /alert-intelligence 页面
  • 保持全局搜索和权限控制功能
验证步骤
  1. 启动应用：npm run dev
  2. 登录任意用户角色
  3. 检查侧边栏是否出现独立的"预警情报"模块
  4. 点击进入 /alert-intelligence 页面
  5. 确认页面正常显示且数据加载正确
  6. 在不同模块间切换，验证预警情报始终可访问
